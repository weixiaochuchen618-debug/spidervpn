# SpiderVPN 用户速查（一页纸）

## 装

1. 解压 ZIP 到任意目录
2. 双击 **一键安装.cmd**
3. 双击桌面 **启动SpiderVPN.cmd**

安装位置 `C:\SpiderVPN`。普通权限即可。
TUN 模式（接管不读系统代理的程序）用 **以管理员身份启动SpiderVPN.cmd**。

第一次运行 Windows 可能提示「已保护你的电脑」：点「更多信息 → 仍要运行」。

---

## 加线路

**有服务器配置**
线路页 →「添加线路」→ 选配置文件（sing-box JSON）→ 命名 → 保存。

**有别人的邀请码**
线路页 →「添加线路」→「我有邀请码」→ 粘贴 → 加入。

**什么都没有，只有一台 VPS**
在程序目录打开终端：

```powershell
spidervpn.exe --server-setup root@你的服务器地址
```

会核对指纹、部署组件、配置 WireGuard、把本机接进去。

---

## 连接

点首页「连接」。连上后：

- 系统代理由 SpiderVPN 接管，断开时还原
- 若之前别的程序改过代理，断开时**不会**覆盖它的改动
- 关窗口只是收进托盘，连接继续；要真正退出用托盘菜单

---

## 三条出口线

| 出口 | 走哪 | 什么时候改 |
|---|---|---|
| 交易 | 自建线路 | 切换会提示，当前连接会断 |
| 日常上网 | 直连 / 服务商 / 交易线路 | 点即生效，不影响交易 |
| AI 助手 | 跟随日常 / 交易线路 | 点即生效 |

应用页可以逐个程序、逐个域名指定走哪条线。

---

## 交易保护（防直连）

有些交易终端不读系统代理，会绕过隧道直接连出去。交易保护用 Windows 内核过滤拦住它们。

- 应用页勾选要保护的程序
- 用**管理员身份**启动，再连接
- 首页「交易保护」显示三态：已保护 / 部分保护 / 未保护
- 未提权时连接照常，但首页会明确写「本次未启用交易保护」

撤销：维护页「解除交易保护」，或卸载时默认解除。

---

## 连接方式（UDP 被限速时用）

线路详情 → 连接方式：

| 方式 | 说明 |
|---|---|
| 标准 | WireGuard UDP 直连，最快 |
| 兼容 | WireGuard over VLESS+REALITY，走 443，抗封锁 |
| 自动 | 用这条线路上次成功的方式 |

只影响下次连接，不打断当前会话。

---

## 加一台新电脑

已连通的电脑上：线路页 →「邀请其他电脑」→ 生成邀请码（默认 30 分钟）→ 新电脑输入。

对方暂时连不上？用「离线邀请」（24 小时有效）。

## 出问题了

| 现象 | 先看这里 |
|---|---|
| 启动报 `0xC0000135` | `WebView2Loader.dll` 没和 exe 放一起，重装一次 |
| 界面打不开 | 装 WebView2 运行时（Win10/11 一般自带） |
| 「端口已被占用」 | 换线路端口重新导入，或关掉占用端口的程序 |
| 连上了但打不开网页 | 跑 `spidervpn.exe --diagnose`，按结论的下一步做 |
| 标准连接自检不通 | `spidervpn.exe --set-transport tcp` 换兼容方式 |
| 交易保护装不上 | 需要管理员权限；未提权时连接不受影响 |
| 断开后上不了网 | 维护页「还原系统代理」 |

诊断输出看不懂时，把 `--diagnose` 的整段文本复制出来，里面每一项都带结论和下一步。

## 数据在哪

```
C:\SpiderVPN\data
  config.json          线路索引与偏好
  lines\               每条线路的引擎配置（含私钥）
  servers\             服务器记录与部署资料
  logs\                操作记录、运行日志
```

卸载默认**保留**数据；要一起删必须手工输入 `DELETE`。

---

## 常用命令

```text
spidervpn.exe                     打开界面
spidervpn.exe --status            连接状态
spidervpn.exe --lines             线路列表
spidervpn.exe --connect           连接
spidervpn.exe --disconnect        断开
spidervpn.exe --diagnose          诊断
spidervpn.exe --history           操作记录
spidervpn.exe --guard-status      交易保护状态
spidervpn.exe --help              全部命令
```
